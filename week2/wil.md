# Weekly I Learned 2

### 스크립트 파일 분리

script 태그 내에 들어가는 내용이 너무 많아지면, HTML의 문서라는 concept를 지키기 어렵다. 따라서 script에 해당하는 내용만 다른 파일로 분리하는 편이 책임 분리 면에서 좋은 선택이다.

먼저 script에 해당하는 내용을 다른 파일로 분리한다. 이후, script 태그를 그대로 사용하는 대신, src 속성으로 해당 script 파일의 위치를 넘겨주면 연결이 완료된다.

- **script 태그는 가장 마지막으로**

    script 태그는 HTML 문서에서 가장 마지막에 위치하는 편이 좋다. 왜 그런지 다음 두가지 이유를 통해 알아보자.

    1. 사용자 경험

        브라우저는 HTML 파일을 한줄 한줄 순차적으로 파싱하는데, 중간에 script 태그를 만나면 해당 js 파일을 다운로드 받고 실행한다.

        때문에 여기에서 소요되는 시간만큼, 사용자에게 화면이 더 늦게 표시된다.

    2. 순서가 꼬임

        HTML 파싱 중간에 스크립트 파일을 실행하게 되면, 해당 스크립트 파일이 필요로 하는 태그가 아직 HTML에서 파싱되지 않았을 가능성이 있다.

        때문에 스크립트 파일이 의도하지 않은 동작을 할 가능성이 생긴다.

### JavaScript

- **변수 선언**

    1. var: 변수 재선언 가능, 재할당 가능
    2. let: 변수 재선언 불가능, 재할당 가능
    3. const: 변수 재선언 불가능, 재할당 불가능

- **함수 선언**

    - `function functionName(parameter)` 형태로 정의
    - JS는 약타입 언어이기 때문에, 변수 및 매개변수에서 따로 자료형을 지정하지 않는다.
    
- **화살표 함수**

    - 짧은 문법으로 익명 함수를 표현하는 기능
    - 객체처럼 다룰 수 있음
    - Java의 lambda와 비슷한 개념

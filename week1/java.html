Java란?

Java는 객체 지향 프로그래밍 언어로, 컴파일러 언어와 인터프리터 언어의 중간 성격을 가진 언어입니다.
Java의 소스 코드는 바이트코드로 컴파일되며, JVM이라고 하는 가상 머신이 바이트코드를 인터프리팅 하여 실행됩니다.
JVM이 OS별로 구현되어 있기 때문에, Java 프로그램은 JVM만 있다면 어떤 OS에서도 실행 가능하다는 것이 특징입니다.

Java 21 주요 기능

  • Switch 문에 패턴 매칭 추가로, 조건문을 간결하게 작성할 수 있게 되었습니다.
  • Record 패턴 추가로, Record 타입 구조를 분해하여 사용할 수 있게 되었습니다.
  • Virtual Threads를 도입하여 스레드 경량화, 높은 동시성 처리 성능을 제공하게 되었습니다.

Java 25 주요 기능

  • 고성능 벡터 연산을 위한 벡터 API가 추가되었습니다.(Preview)
  • 불변 String의 hashcode를 컴파일 타임에 결정하여, String을 Key로 하는 Map에서의 성능이 향상됩니다.

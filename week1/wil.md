# Weekly I Learned 1

### HTML

HTML 문서를 작성하며, *index.html*, *java.html*에 사용된 태그 및 공부한 내용들을 다음과 같이 정리한다.

- **필수 HTML 코드 편하게 입력하기**

    VS Code 기준, 빈 HTML 문서에서 `!`를 입력하면 *Emmet Abbreviation* 기능을 통해 DOCTYPE 문서 틀(`head`, `body`, `title` 등)을 자동으로 생성할 수 있다.

- **주석 넣기**

    html 코드에 주석을 삽입하려면, `<!--주석 내용-->`을 사용하자.

- **ul 태그**

    순서 없는 목록을 표시하려면 `ul`(*unordered list*) 태그를 사용한다.

    목록의 각 항목을 나타내려면 `li` 태그를 통해 작성 가능하며, `ul` 태그의 시작과 끝 사이에 존재해야 한다.

    비슷하게, 순서 있는 목록을 표시하려면 `ol`(*ordered list*) 태그를 사용한다.

- **`a` 태그와 `link` 태그의 차이**

    HTML에서 링크 형식을 받을 수 있는 태그로는 1주차 강의에서 배운 `a`(anchor) 태그가 대표적이지만, `link` 태그 또한 존재한다.
    
    이 두 태그는 모두 속성으로 `href`를 받을 수 있어 헷갈릴 수 있다.

    - `a` 태그
        
        `body` 안에 작성하고, 클릭 시 해당 주소로 이동한다. (ex. 다른 문서 또는 웹 페이지 하이퍼링크)

    - `link` 태그
        
        `head` 안에 작성하고, 현재 페이지를 외부 데이터와 연결한다. (ex. 폰트 파일 제공)

    비슷하게 `img` 또한 링크 형식을 받을 수 있지만, 이쪽은 src 라는 attribute를 통해 이미지의 출처를 직관적으로 나타낸다.

- **꺾쇠 기호 넣기**

    html 코드에는 태그를 구분하기 위해 꺾쇠(<, >)가 많이 들어간다. 이 때문에 태그 안 content에 꺾쇠 기호를 넣으면, 태그라고 인식되어 의도한 대로 문서가 작성되지 않을 수 있다.
    
    꺾쇠 기호를 올바르게 넣고 싶다면, `&lt;`(앰퍼샌드 less than ;), `&gt;`(앰퍼샌드 greater than ;) 을 통해서 넣어줘야 한다.

- **index.html**

    *index.html*은 특별하게 동작하며, 어떤 웹 페이지 묶음의 최상단(대표) 페이지를 나타낸다. 이는 생략 가능하며, google.com 또한 google.com/index.html 이 축약된 결과이다.

### JavaScript

HTML에서, script 태그 내에 JavaScript를 작성하여 브라우저 상에 특별한 동작을 취해줄 수 있다.

- `console.log` 를 통해 개발자 도구의 콘솔에 로그를 작성할 수 있다.
- `alert` 를 통해 브라우저 상에 알림창을 띄울 수 있다.
